## 上传范围与复现

上传报告、CSV/JSON 原始测量、测试日志、复现脚本、源码快照、diff、PNG/SVG。`runs/` 和 `outputs/` 继续在 .gitignore 中，避免日后自动收录新运行产物；本次已明确选择的实验文件由 Git 跟踪。各报告中的服务器绝对路径用于追溯原始环境，下载后请按本地位置调整。

不上传数据集、权重、CUDA 动态库/编译缓存、Nsight 二进制报告/SQLite、Python profiler 二进制和重复压缩包。报告中的归档清单描述服务器原始归档，可能列出本次 Git 发布排除的文件；它们不代表 Git checkout 的文件清单。需要重新生成的产物见各阶段 REPRODUCE.md 与构建脚本。EXTERNAL_ARTIFACTS.json 提供原始服务器路径与校验值，不保证其他机器能访问这些路径。

监控默认关闭。启用示例：

```bash
python benchmarks/bench_cuda_training.py --device cuda --gpu 0 --model donkey --samples 256 --batch 4 --epochs 3 --final-config --monitor --monitor-interval 0.2 --output runs/monitor_new
```

运行 GPU 实验前先检查空闲设备与使用权限，`--gpu` 是当前进程的逻辑 GPU 编号。
