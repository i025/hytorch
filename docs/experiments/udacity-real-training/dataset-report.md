## 固定时间划分

center文件名时间覆盖2016-12-01 13:30:48.287–13:46:38.947，CSV时间顺序无倒序。按时间排序的最后20%作为验证；训练候选与首个验证帧之间保留10秒隔离：

- 训练6330，验证1608，隔离剔除98。
- 最后训练与最早验证相隔10.037秒，没有相邻视频帧跨边界。
- 每轮训练顺序为seed42+epoch的固定排列，四后端完全相同；验证保持时间顺序。
- 吞吐实验从训练索引以seed42选1024张，三重复及四版本使用完全相同顺序；不按标签重新平衡。

这减少邻帧泄漏，但数据来自同一轨道/采集片段，可能仍重复经过相同场景。验证只能代表此时间留出集，不能证明跨轨道、跨天气或闭环驾驶泛化。零转向占比较大，报告同时给出零预测基线，不只看Loss下降。

## 统一预处理

RGB→裁掉顶部70/底部25行（160→65）→Pillow bilinear resize至宽200/高66→float32归一化`pixel/127.5−1`→连续CHW，输出`[3,66,200]`。训练与验证使用同一函数，无随机增强。未来单图推理应复用`preprocess_udacity`，本轮未接入Unity。
